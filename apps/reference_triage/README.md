# التحقيق المرجعي الاصطناعي — FAST3

افتح `/dev/reference-triage` على خادم التطوير المحلي الحالي. ولعرض العينات
دون فحص قاعدة بيانات، يمكن استخدام المشغّل الموجود `python -m apps.editorial_queue`
ثم فتح <http://127.0.0.1:8014/dev/reference-triage>.

تعرض الشاشة الحالات العشرين الموجودة بالفعل: سجل المراجعات الثابت، وثمانية
صفوف Wave7، وأحد عشر صفًا من دفعات FAST2. تستدعي
`build_cases()` و`build_prepared_workbench()`؛ الخدمات الحالية هي صاحبة قرارات
التشخيص والحل. لا يوجد محلل إحالات بديل أو بحث في الفهرس المحمي أو مصدر جديد.

التعداد الحالي: 15 مؤشرًا، منها 8 مطابقة تقنيًا و7 غير محسومة و0 متعارضة؛
8 سجلات بلا مؤشرات قابلة للعرض. يعرض الصفر كما هو، دون اختراع حالة تعارض.
تغطي الاختبارات عرض التعارض عبر نتائج خدمة مصطنعة للاختبار فقط.
تظهر الدفعة المتعذر تحليلها مع بصمتها وسببها وإرشاد استعادتها دون إنشاء صفوف.
قبول الاستلام مستقل عن التحقق المرجعي؛ لا تخفي الشاشة إحالات الصفوف المرفوضة.

التصفية حسب الدفعة وحالة أي مؤشر، مع السابق والتالي والعودة إلى النتائج،
وروابط السجل المقابل في مساحة العمل. تعرض ملخصات السجلات المنتقاة كل إحالاتها؛
السجل ذو حالات متعددة قد يظهر في أكثر من تصفية، لكن كل مؤشر يعد مرة واحدة
داخل الملخص. لا تجمع أعداد السجلات بين تلك التصفيات.

تعرض التفاصيل الحالة والسبب الأصليين، الشروح التي وفرتها الخدمة، الهوية
المدخلة وهوية المطابقة والدليل المتاح، دون استنتاج حقول مفقودة. `null` تعني
دليلًا غائبًا، و`{}` تعني هوية غير مسجلة؛ قد تعرض خدمة التحضير مطابقة تقنية
وهوية دون كائن دليل تفصيلي. يبقى ذلك ظاهرًا ولا يستكمل العرض بياناتها.
هوية المرجع في سجل `history` تخص أحدث لقطة ثابتة، لا كل مراجعاته.

بصمات المدخلات مستقلة عن بصمات النصوص المعروضة. تحفظ شرائح Wave7 حدود
UTF-8 الأصلية؛ صفوف FAST2 المحللة وسجل المراجعات مسلسلة صراحة دون ادعاء
حدود بايتات أصلية. تُهرب HTML أولًا ثم تحفظ CR بمراجع محارف حتى تبقى العربية
والتشكيل وCRLF كما هي عند قراءة نص DOM؛ لا تطبيع للنصوص أو الهويات.

كل المسارات تحت الحاجز الموجود `local_only` و`require_safe`: مضيف وطرف اتصال
loopback، رفض الإنتاج، GET/HEAD فقط، و`Cache-Control: no-store`.
لا رابط عام لهذه الشاشة، ولا API عام للهويات التقنية. تعاد الاستفادة من
CSS مساحة العمل المحمي. لا نماذج أو ترحيلات أو تغييرات إعدادات أو صلاحيات،
ولا كتابة أو اعتماد علمي أو نشر. إزالة include الوحيد وملفات هذا المسار
تكفي للتراجع؛ لا ترحيل بيانات.
