## User-visible work

The existing private rights desk now opens a registered source through a native
“تفاصيل الحقوق ومقارنة الإصدارات” button. Its inspection shows exact origin,
source/edition/position and original input/archive/snapshot pins; private transcript
identity never includes its question text. It distinguishes book-622 **TOC metadata**
from an actually stored private transcript. It shows current READ/CITE/RELATE/
PREVIEW_METADATA separately from unsupported FULL_TEXT/QUOTE/PUBLISH. A citation is
not a quotation, preview metadata is not publication of the source, and a private
transcript cannot acquire public/citation uses. Unsupported uses have explanations
and no grant controls; backend proposal/permission denials are preserved.

A native revision selector compares the selected immutable decision to its actual
predecessor: uses, documentary basis, rationale and expiry. Current availability is
always shown separately from the selected historical revision. Pending replacements,
expired/revoked rights and changed source identities remain non-granting. History
can still be inspected by the independently authorized rights reviewer. Existing
review forms now show only eligible actions on the latest revision for the actual
explicit authority; self-approval and stale revisions have no approval control.
Backend checks remain decisive and unchanged.

Both templates use `casework/base.html`, retaining the selected-case frame. Return
forms preserve the source query and edition, or return to `case_workspace`. No
technical identifier is typed by the user and no query parameter grants scope.

## Integration contract

Existing `views.ACTIONS` gains `rights_inspect`. Shared dispatch already routes
this set. If the shared Mufti frame uses a fixed eligibility list, include this
new action there. No new route/flag is required. Keep existing case authentication,
CSRF, loopback, request budgets, no-store and strict maintenance middleware.

The native POST fields are `action`, `case_ref`, hidden `source_id`,
`revision_number` (0 = latest, otherwise exact saved 1–64), `query`, `edition_id`
and CSRF. Unknown/duplicate fields and files are refused. Return fields are bounded
and used only as navigation state. `registry.inspect_source(...)` requires current
case scope, SourceRightsAuthority VIEW, actual source registration in that same
case and a valid snapshot digest. It is covered by `mutation_service` admission.
It returns private review data, never an access capability or general search grant.

Selectors: `#rights-material-kind`, `#rights-usage-matrix`, `#rights-current-status`,
`#rights-revision-comparison`, `#rights-inspect-revision`. Each usage row has
`data-rights-use` and `data-rights-state`. Controls: “عرض مقارنة الإصدار” and
“العودة إلى نتائج المصادر نفسها”. Source labels and evidence are ordinary escaped
text; no original transcript/book text, file link, key or public URL is exposed.
