## التسليم التشغيلي

- `apps/fatwa_drafts/intake.py`: عقد `fatwa.prepared-intake.v1`، فك UTF-8 صارم، حدود حجم/عدد/طول، رفض مفاتيح JSON المكررة والحقول غير المعروفة والمعرفات المكررة والمراجع الجزئية، وتسلسل حتمي قابل لإعادة القراءة.
- `apps/fatwa_drafts/domain.py`: dataclasses ثابتة، السؤال وبيانات الاستلام الأصلية محفوظة؛ عنوان وإجابة يُمرران صراحة من محرر بشري فقط، ملاحظات مراجعة وتحرير، وسجل كامل لكل إصدار. لا يوجد توليد إجابات أو استنتاج مصادر.
- `SyntheticStage`: مخزن داخل ذاكرة العملية للاختبارات الاصطناعية فقط، إدخال دفعة ذري، تعديل محمي برقم إصدار متوقع وقفل داخل المثيل؛ تعارض الإصدار لا يبدل السجل. خدمات الإنشاء/التعديل/الانتقال تعمل أيضًا على سجلات منفصلة دون مخزن.
- `preview()` تقرير JSON حتمي للقراءة، يحجب افتراضيًا المعرف والسؤال والرابط والإجابة والملاحظات وأسماء المحررين وجميع النصوص الحرة، بما فيها history. الخيار الصريح `include_synthetic_content=True` يكشف سجل الاختبار فقط. هذه الإشارة تصريح من المستدعي وليست كاشفًا آليًا للبيانات الحساسة؛ لا تستخدم الوحدة مع بيانات خاصة.
- `python -m apps.fatwa_drafts` مثال مستقل قابل للتشغيل، ينشئ مثالًا اصطناعيًا وينتج معاينة محجوبة فقط. لا ملفات إدخال أو حفظ أو قاعدة بيانات أو شبكة.

## الحالات والمتطلبات

`received -> draft_preparation -> needs_revision / ready_for_future_review`.
يمكن إعادة `needs_revision` إلى التحضير، وإعادة الجاهز إلى `needs_revision`. التعديل النصي مسموح في التحضير أو طلب التعديل فقط. كل عملية تتطلب اسم محرر وملاحظة تحرير ورقم إصدار صحيح؛ الجاهزية تتطلب عنوانًا وإجابة بشرية غير فارغين. اسم المحرر وسم يدوي وليس مصادقة أو منح صلاحية. لا timestamps مخترعة؛ ترتيب الإصدارات تسلسلي وحتمي. لا حالات اعتماد أو نشر، ولا أدوار أو واجهات خاصة حية.

غياب المرجع اليدوي لا يمنع استلام المسودة أو جاهزيتها **لمراجعة مستقبلية**؛ المعاينة تعرض `missing_manual_references`. وجوده يعرض `unverified_editorial_pointers` ولا يعني صحة الاستشهاد أو الموافقة عليه. العناوين المرجعية الـ11,397 ليست فتاوى.

## عقد المراجع مع C1/C3

`reference_links` اختياري ويقبل قائمة فارغة. كل عنصر عند تقديمه يتطلب نصوص الهوية التالية دون تخمين أو تطبيع:

```json
{
  "source_namespace": "synthetic",
  "source_book_id": "TEST-BOOK",
  "edition_key": "TEST-EDITION",
  "source_archive_sha256": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "source_input_sha256": "bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb",
  "source_id": "TEST-HEADING"
}
```

هذه هوية اصطناعية وليست ربطًا بمصدر فعلي. الـSHA يتطلب 64 خانة hex صغيرة. الهوية الناقصة أو الحقول الإضافية خطأ صريح، والهوية الكاملة تحفظ كما أُدخلت؛ لا تحقق من وجود عنوان في المصدر في هذه الموجة. هذا تخصيص محلي للجزء الاختياري من العقد المشترك وينبغي توحيده مع C1/C3 قبل الربط. لا يُحوَّل سؤال إلى مرجع آليًا.

الرابط رابط HTTPS جاهز مقدم من الموظف؛ رفض بيانات دخول مضمنة وfragment ومنافذ غير 443. التحقق نحوي فقط، ولا يفحص الوصول أو الملكية أو المحتوى. لا تنزيل ولا قص ولا تحويل ولا تفريغ ولا توليد صور. كل تجهيز الوسائط خارج المنصة بواسطة الفريق البشري.
