# استقبال بيانات المقاطع الجاهزة — C1

أداة محلية بمكتبة Python 3.13 القياسية. مثال تشغيل من جذر المستودع:

`python -m tools.content_intake export docs/dev/c1/sample.csv --bundle docs/dev/c1/local-bundle`

الأوامر `validate INPUT` و`preview INPUT` تعرض التحقق أو معاينة الغلاف مع البيان؛ `export INPUT --bundle DIRECTORY` ينشئ حزمة جديدة؛ `check INPUT --bundle DIRECTORY` يعيد حساب كل المخرجات ويقارنها حرفياً بما في الحزمة. رمز الخروج 1 للأخطاء و0 للسجلات الصالحة تقنياً، بما فيها REVIEW_REQUIRED. يجب قراءة الحالة والملاحظات دائماً؛ النجاح التقني ليس موافقة تحريرية. المعاينة قد تعرض الصفوف الصالحة فقط مع أخطاء بقية الصفوف؛ التصدير يرفض المجموعة كاملة عند وجود خطأ.

المدخل CSV أو JSON (مصفوفة أو غلاف العقد) أو JSONL (كائن لكل سطر غير فارغ)، UTF-8 صارم مع قبول BOM في بداية الملف. أرقام الصفوف هي ترتيب السجل بدءاً من 1، باستثناء الترويسة؛ الأسطر الفارغة في JSONL لا تحسب. أخطاء البنية/الترميز تظهر على مستوى الملف. يُرفض تكرار مفاتيح JSON والترويسات والأعمدة غير المعروفة.

تسليم الموظف هو الغلاف `fatwa.prepared-intake.v1` بمصفوفة `items`. كل عنصر يحوي `external_id` ثابتاً وفريداً بلا فراغات طرفية، `question` غير فارغ، `prepared_clip_url` نص رابط HTTP/HTTPS جاهزاً أو نصاً فارغاً يحتاج مراجعة، `staff_notes` نصاً، و`reference_links` مصفوفة. يمكن تقديم `title` بدلاً من `question` في المدخل فقط؛ وجودهما بقيم مختلفة خطأ غموض. تزال الفراغات الطرفية من النصوص غير المعرّف دون تطبيع الحروف أو إزالة علامات RTL.

كل رابط مرجعي يدوي حصراً هو `{"source_id":"SYNTHETIC","heading_id":"TEST-1"}`؛ القيم نصوص غير فارغة. في CSV تكتب المصفوفة بصيغة JSON داخل خلية مع قواعد اقتباس CSV. هذه مؤشرات تحريرية إلى عناوين فهرس، لا فتاوى ولا مطابقة مؤكدة؛ لا تتحقق الأداة من وجودها في قاعدة بيانات ولا تستنتجها من السؤال. الحقول الأخرى تحتاج اتفاق عقد لاحق وتُرفض الآن.

الحزمة تضم `intake.json` و`intake.jsonl` و`manifest.json`. البيان يحتوي SHA256 للمدخل الخام ولكل مخرج وعدد البايتات والصفوف والنتائج الدقيقة، دون توقيت متغير أو مسار محلي. `check` يتحقق من الاتساق وإعادة الإنتاج، وليس توقيع أصالة. ترتيب السجلات محفوظ والمفاتيح مرتبة. رابط غائب يظل فارغاً مع REVIEW_REQUIRED؛ لا يُخترع رابط. النص الذي يبدأ بعلامة صيغة جدول يحتفظ بقيمته ويولّد ملاحظة مراجعة؛ المخرجات JSON فقط، ولا ينبغي لصقه كصيغة في جدول بيانات.

الكتابة محصورة بملفات ثابتة داخل مجلد حزمة جديد تحت مجلد التشغيل، مع رفض المجلد الموجود والمسار المحلول خارج مجلد التشغيل. لا حذف أو استبدال ملفات، ولا إنشاء مجلدات آباء. استخدم مجلد عمل موثوقاً محلياً؛ لا تشارك صلاحية الكتابة فيه مع عملية معادية أثناء التصدير. المدخلات تقرأ كاملة في الذاكرة؛ هذه أداة دفعات موظفين محلية وليست خدمة استقبال عامة.

`sample.csv` و`expected/` بيانات اصطناعية فقط. لا تنزيل أو معالجة وسائط أو اختيار أزمنة أو API أو قاعدة بيانات أو اعتماد أو نشر. الفهرس الأصلي ذو 11,397 عنواناً يظل خارج هذه الأداة وغير معدل.

الاختبارات: `python -m unittest discover -s tests/content_intake -v`.
