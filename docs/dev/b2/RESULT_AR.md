# نتيجة B2 — البحث العربي وموثوقية فهرس القراءة فقط

التاريخ: 2026-10-16. أساس العمل: `7a44bdf28874f9113acbe82cb6fdb64baf87da89`.
التعديلات محلية غير ملتزم بها. **NOT_DEPLOYED / GATES_HOLD**؛ Gate B NOT_PASSED،
Gates C/D/E HOLD، Phase01 BLOCKED، وسياسات U03/U10 بانتظار قبول المالك.

## التغييرات

- فصل عدّ أبناء العنوان في استعلام ORM فرعي مرتبط بالعنوان والطبعة؛ استعلام إجمالي
  نتائج البحث لا يحتاج الآن إلى تجميع عناوين النتائج وأبنائها. لا ادعاء بتحسن زمني دون قياس.
- إذا كان الإجمالي صفرًا أو كانت الإزاحة عند النهاية أو بعدها، لا يُنفذ استعلام جلب الصفوف؛
  تبقى الإزاحة المطلوبة والإجمالي الحقيقي في الاستجابة، و`next_offset=null`.
- نطاق الجذر يطابق المفتاح الداخلي والطبعة عند كل سلف، ويتحقق من تسلسل الأعماق حتى خمسة.
  المسارات المعيبة ذات الأعماق غير المتسقة لا تدخل نتائج النطاق. هذه دقة إضافية للبيانات
  المعيبة؛ لا تغيير متوقع لنتائج الشجرة الصحيحة.
- إزالة شروط الكلمات المكررة بعد التطبيع، مع بقاء التطبيع الأصلي والعناوين الأصلية كما هما.
- إصلاح مساعد الاختبار ليستبدل مؤشر الاتصال الفعلي بدل وسيط Django، حفاظًا على منع الاتصال
  عند إنهاء فئات الاختبار، وتوحيد مسارات استيراد الاختبارات في المشغّل المعزول.

## العقد المحفوظ

لا حقول أو نقاط نهاية جديدة. `exact` يطابق العنوان الأصلي كاملًا دون قصه؛
`literal` يبحث بكل الكلمات داخل العنوان الأصلي؛ `normalized` يبحث بكل الكلمات بعد
التطبيع الحالي. `%` و`_` نص حرفي مربوط بمعلمات ORM، وليسا محارف بحث شاملة.
البحث الفارغ أو الذي يزول بالتطبيع يعيد نتائج فارغة، مع التحقق من نطاق الجذر أولًا.
الحدود الحالية: 160 محرفًا وعشر كلمات، limit بين 1 و100، offset بين 0 و20000.
ترتيب البحث يبقى `source_order, source_row_id` داخل الطبعة المحددة، وترتيب الأشقاء
`position, source_order, source_row_id`. لم يتغير ترقيم المرساة أو منع جمعها مع offset.
اختبار الاستجابة يثبت قائمة الحقول وهوية المصدر، واختبارات SSR السابقة ما زالت ناجحة.

## التحقق الفعلي

Python 3.13.15، Django 5.2.18. ثُبتت اعتماديات requirements.txt في بيئة مؤقتة خارج المستودع.
لإعادة التشغيل استعمل Python من بيئة الاعتماديات:

```powershell
python -B tests/integration/api/run_isolated.py
ruff check apps/reference/services.py tests/integration/api
ruff format --check apps/reference/services.py tests/integration/api
python -B manage.py check
node --test tests/integration/ui/adapter.test.mjs tests/integration/ui/catalog.test.mjs tests/integration/ui/tree.test.mjs
git diff --check
```

- اختبارات API المعزولة: **25 ناجحة**، منها **9 جديدة**. تشمل الإدخال غير الصالح والفارغ،
  النطاق والعمق الخامس، العربية والتطبيع والمحارف الحرفية، نهاية الصفحات، حد المرساة،
  حقول الاستجابة، وSQL المربوط بالمصدر والمرتب ترتيبًا ثابتًا.
- عدّ عمليات SQL في المؤشر الاصطناعي: بحث غير فارغ بصفحة نتائج = عمليتان؛ داخل الجذر = ثلاث؛
  صفحة فارغة/بعد النهاية = عملية عدّ واحدة؛ بحث مطبع فارغ بلا نطاق = صفر؛ مرساة الأشقاء = أربع.
  هذه أعداد مضبوطة لمسار الخدمة، ولا تشمل حل الطبعة في واجهة HTTP.
- اختبارات واجهة Node المذكورة: **20 ناجحة**. ليست اختبار متصفح أو قارئ شاشة فعلي.
- Ruff lint والتنسيق، Django system check، وgit diff --check: **ناجحة**.

هوية بيانات الاختبار: صفوف اصطناعية `a2-cursor-rows-v1` من المساعد الموجود، مع نصوص B2
في `tests/integration/api/test_b2_search.py`. المؤشر يعيد صفوفًا مجهزة؛ Django يولد SQL
ويحوّل الصفوف فعلًا، لكن الاختبارات **لا تنفذ شروط البحث على PostgreSQL** ولا تثبت خطة التنفيذ
أو ترتيب البيانات الفعلي في القاعدة. لم يُشغّل اختبار PostgreSQL أو قياس أداء للمصدر الحقيقي؛
لا توجد نتيجة قبول جديدة للعناوين الـ11,397 أو للملف الأصلي. يمنع المشغّل المعزول أي اتصال قاعدة.

التوقعات ومساعد المؤشر، ثم نجح التشغيل الكامل المذكور أعلاه.
