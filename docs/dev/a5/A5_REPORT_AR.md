| نوع الدليل | ناجح | فاشل |

شملت الجولة 458 طلب HTTP واجتياز 11,397 عنوانًا عبر 285 صفحة، مع 32 جذرًا وعمق 5.
تطابقت بصمة المحتوى المجمّع مع عقد المصدر المثبّت، وظلت بيانات الطبعة محفوظة.
الفهرس لكتاب 622 وحده، مع بيان واضح أنه ليس فتاوى معتمدة أو تصنيفًا عامًا.
لم تُعِد هذه المراجعة حساب بصمة ZIP الأصلي.

العيوب الثلاثة القابلة لإعادة الإنتاج:

- A5-001: يقبل محوّل الواجهة تغيّر بيانات وصف الطبعة والعمل مع ثبات البصمات؛ دليل اصطناعي.
- A5-002: يقبل جذرًا غير جذري ومسارًا لا يوافق العمق؛ اختباران اصطناعيان.
- A5-003: عند 17 معلمة يعيد API خطأ 400 بصيغة HTML إنجليزية بدل JSON؛ دليل HTTP فعلي.

توجد أيضًا ملاحظة سلامة بيانات ثابتة للمنسق: مشغلات UPDATE/DELETE لا تثبت منع
إضافة عنوان جديد إلى طبعة مكتملة؛ لم تُفحص صلاحيات INSERT ولم يُجرَّب ذلك على DB.
البيانات الحية الحالية تطابق البصمة المثبّتة.

أُضيفت 7 اختبارات Django معزولة، منها تهريب عنوان مصدر عربي ضار في القوالب، لكنها
**غير منفّذة**: لا يتوفر Python. فحص المتصفح/الجوال/لوحة المفاتيح واختبارات PostgreSQL
المباشرة غير منفّذة؛ لا يوجد متصفح متصل، ولم تُفتح جلسة DB.
